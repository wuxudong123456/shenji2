# 审计实务工坊 — 需求规格说明书

## 1. 产品定位

面向国家审计人员的 AI 多智能体审计分析平台。以 OpenSquilla 为 AI 运行时底座，向上扩展审计领域三大工坊。

## 2. 基础设施需求

| 需求 | 说明 | 现有服务 |
|------|------|---------|
| **AI 运行时** | OpenSquilla 全功能：MCP/Skills/Agents/Memory/Search/Scheduler/Sandbox/Desktop/CLI | RC4 已部署 164:18791 |
| **LLM 网关** | 文本推理 + 多模态视觉 | 192.168.3.189:8765 / 8767 |
| **对象存储** | 按审计项目自动创建独立 Bucket | MinIO 192.168.3.164:9100 |
| **OCR 引擎** | 文档解析为 Markdown，保留页码/坐标溯源 | MinerU 192.168.3.189:5005 |
| **元数据抽取** | 1511 审计模板匹配，结构化抽取 | OntoSKU 192.168.3.189:5005 |
| **向量检索** | 法规语义搜索、违规模型匹配 | FAISS + audit_law 库 |
| **数据库** | 业务数据持久化 | MySQL 192.168.3.164/tt |

## 3. 安全需求

| 需求 | 要求 |
|------|------|
| **沙箱保护** | 所有代码执行、文件操作经 OpenSquilla sandbox 隔离，不可绕过 |
| **记忆保护** | OpenSquilla Memory **项目级隔离**，每个审计项目独立上下文，切换项目自动切换 |
| **溯源不可篡改** | OCR 结果、法规引用、分析结论均带溯源锚点，可追溯到原始文件页码/位置 |
| **人机确认断点** | AI 推荐必须经人工确认才能执行，不可跳过（审计责任在人不在于 AI） |

## 4. 功能需求 — 三大工坊

### 4.1 资料工坊

| ID | 需求 | 详细说明 |
|----|------|---------|
| DW-01 | 项目 Bucket 自动创建 | 创建审计项目 → 自动在 MinIO 建立独立 bucket |
| DW-02 | 文件上传 | 支持 PDF/Word/Excel/图片，拖拽上传 |
| DW-03 | 自动 OCR | 上传后自动调用 MinerU 解析为 Markdown |
| DW-04 | 版本管理 | OCR 结果保留多版本，用户修正后存新版本，旧版本可回溯 |
| DW-05 | OntoSKU 抽取 | OCR 文本 → 匹配 1511 模板 → 提取结构化字段 |
| DW-06 | 溯源锚点 | 每个抽取字段关联原始文件页码/坐标，点击可定位原文 |
| DW-07 | 重新推理 | 支持切换模板重新抽取，覆盖原结果或并存 |
| DW-08 | 资料状态面板 | 显示每份文件：解析状态、字段数、记录数、更新时间 |

### 4.2 数据工坊

| ID | 需求 | 详细说明 |
|----|------|---------|
| DD-01 | 结构化数据表 | OntoSKU 抽取结果自动入库（核心列 + JSON 扩展混合方案） |
| DD-02 | 数据浏览 | 分页表格展示，字段排序/筛选 |
| DD-03 | 智能问数 | 用户自然语言 → LLM 转伪 SQL → 执行查询 → 表格结果 |
| DD-04 | 伪 SQL 确认 | LLM 生成的查询语句经用户确认/修改后才执行 |
| DD-05 | 多维度筛选 | 时间范围、字段值、分类等组合筛选 |
| DD-06 | 数据导出 | 支持 CSV/Excel 导出 |
| DD-07 | 可扩展字段 | JSON 列支持模板字段扩展，无需 ALTER TABLE |

### 4.3 知识工坊

| ID | 需求 | 详细说明 |
|----|------|---------|
| DK-01 | 违规行为库 | 2195 违规模型检索（关键词 + FAISS 语义搜索） |
| DK-02 | 法规依据库 | 40 万+法规全文检索，效力级别/时效性/区域类型筛选 |
| DK-03 | 法规关系链 | 上位法→下位法→相关法→历史版本，以任一法规为中心展开 |
| DK-04 | 条款分析 | 法规→7 类条款分类（定性/处罚/移送/法规依据等） |
| DK-05 | 审计案例库 | 案例→违规模型→法规依据→定性结论，三向关联知识网络 |
| DK-06 | 违规表达式引擎 | 伪 SQL 表达式 → 对数据工坊表逐行扫描 → 命中/未命中标记 |
| DK-07 | 可视化比对 | 表达式树 + 扫描动画 + 命中高亮 + 实时统计 |
| DK-08 | 疑点报告 | 命中记录 → 关联法规 → 构建证据链 → 导出结构化报告 |

## 5. 功能需求 — 智能分析（六步向导）

| ID | 步骤 | Agent | 说明 |
|----|------|-------|------|
| DA-01 | ① 输入意图 | IntentAnalyzer | 审计领域 + 事项描述 + 期间 + 对象层级 |
| DA-02 | ② Agent 推荐 | ViolationMatcher / DataAdvisor / RegulationAdvisor (并行) | 推荐违规模型 + 资料清单 + 候选法规 |
| DA-03 | ③ 选择依据 | 人工交互为主 | 法规关系树 + 条款浏览 + 自定义补充 + 确认面板 |
| DA-04 | ④ 上传资料 | MinerU + OntoSKU | 文件上传 → OCR → 模板匹配 → 元数据提取 |
| DA-05 | ⑤ 智能分析 | AuditAnalyzer | 逐模型比对 + 异常检测（文本 + 多模态） |
| DA-06 | ⑥ 疑点报告 | SuspiciousPointGen | 结构化疑点列表 + 证据链 + 导出 |
